# Basekeeper: Smart Storage & Inventory

Basekeeper is a lightweight, modular Project Zomboid Build 42 mod for automating repetitive storage and inventory work without bypassing the survivor or the world.

Items remain in physical containers. The survivor still walks, carries each load, respects encumbrance, and uses vanilla-style timed actions. Basekeeper is intended to feel like a focused vanilla+ assistant rather than a remote inventory or UI replacement.

Planned first-release features include:

- Explicitly configured smart-storage containers and rectangular storage zones.
- Preset and player-defined categories for vanilla and modded items.
- Priority-aware Consolidate, Balance, and Nearest routing.
- Physical Unload and Organize operations with Safe and YOLO hauling modes.
- Shared multiplayer zones with small, server-authoritative permissions.
- A compact Zone Manager and lightweight inventory layout options.
- An optional Paper Doll view backed by vanilla equipment state.

Basekeeper targets the current public-stable Build 42 line, beginning with 42.20.2. It is in early development and has not yet been released.
